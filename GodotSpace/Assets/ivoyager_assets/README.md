# ivoyager_assets

See version in assets.cfg.

The ivoyager_core editor plugin manages download and update of assets via a popup dialog. Press "Download" when prompted to add or update assets in directory res://addons/ivoyager_assets/.

Alternatively, you can download release or development assets and add them manually. These can be found [here](https://github.com/ivoyager/asset_downloads).

The master ivoyager_assets repository is maintained in a private LFS (Large File Storage) Git repository by Charlie Whitfield. It's not a public submodule for two main reasons: 
1. GitHub charges for bandwidth when LFS repositories are cloned or forked, but not when downloaded.
2. Users would have to install Git LFS.

## asteroid_binaries

Asteroid binaries were created with ivbinaries_maker v0.3 using source data downloaded on 2024-09-09.

For details, see https://github.com/ivoyager/ivbinary_maker.
